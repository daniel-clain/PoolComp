# All based on comp number of registered players (NORP)

- everything derives from this
- 1st prize calculated from NORP
- big comp set aside calculated from NORP
- Christmas is $20 taken from each week's big-comp set-aside half (every comp, not only big comps)

# Each comp assumes everyone has paid

- the paid flags next to each player are a reminder to chase, but not the source of truth for how much has been paid

# Monthly big comp auto builds and clears as each big comp is held

- the big comp fund is the sum of `(buy-ins / 2) − $20` from the last big comp plus every normal comp since then
- on big comp night that fund is added to this week's normal first prize to make the total prize pool
- tonight's own set-aside starts the fund for the next big comp

# Christmas fund auto builds and clears as each Christmas event is held

- every weekly comp contributes a flat $20 Christmas cut from the non-prize half of the buy-ins
