# The main value provided by the app

- the first round random matchups are generated by the app so that the manager of the pool comp no longer has to figure out random matchups by drawing numbers from a bag, which will make things a lot quicker and easier to set up the pool
- the manager doesn't have to mathematically do the calculation of what the prize money is and how much is owed to the bar because the app will do the calculation for them

# Secodary value provided by the app

- have a persistent list of players so that when adding players to the pool comp it's a matter of looking at the existing list and tapping their name to add them to the comp, and if that player isn't already in that list then adding them to that list and then the comp
- players that have been added to the compI have a flag of whether they've paid or not so that the manager can keep track of who has and hasn't paid
- persist data of each in a database so that a list of historical comps can be stored and referenced for revision, reference and reporting
  - getting the average of the of each player's performance over time
  - how many times a player has won this year
  - what is the overall ranking of players based on their results
  - what is the attendance rate of each player
